3.1
1.包声明：package 包名;（IDEA 自动生成，包名全小写分层）
2.类定义：public class 类名 {}，class是全小写高亮关键字，{}界定类范围
3.主入口：main方法是程序入口，固定格式public static void main(String[] args) {}
4.输出语句：System.out.println("内容");，括号内可输出字符串 / 数字
5.注释：单行//（快捷键 Ctrl+/）、多行/* */（Ctrl+Shift+/），不影响运行，不嵌套
6.关键字：全小写、高亮显示（如class），有特殊含义
7.字面量；程序中使用的数据，如变量、常量、参数
类型；
整数类型	直接写数字	                     18、180
小数类型	直接写，必须加小数点	             100.5、3.14
字符串类型	双引号 " " 包裹，内容长度不限	 "我的身高 180"
字符类型	单引号 ' ' 包裹，仅一个字符	         ' 男 '、'A'
布尔类型	仅两个值：true（真）、false（假）	 true、false
空类型	特殊值 null，表示无对象	             null
