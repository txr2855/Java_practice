# 程序三种基本执行结构完整总结
## 一、顺序结构（最简单的执行方式）
### 核心概念
顺序结构就像我们日常做事的“一步接一步”，代码从上到下、从左到右**依次执行**，没有任何跳过或重复，是程序最基础的执行结构。

### 代码示例
```java
public class SequenceStructure {
    public static void main(String[] args) {
        // 第一步：定义变量
        int a = 10;
        int b = 20;
        
        // 第二步：计算求和
        int sum = a + b;
        
        // 第三步：输出结果
        System.out.println("a + b = " + sum);
        
        // 第四步：执行后续语句
        System.out.println("程序执行完毕");
    }
}
```

### 执行流程&结果
1. 先定义变量 `a=10`、`b=20`
2. 再计算 `sum = 10+20=30`
3. 然后输出 `a + b = 30`
4. 最后输出 `程序执行完毕`

**输出结果**：
```
a + b = 30
程序执行完毕
```

### 关键特点
- 所有代码都会被执行，无遗漏、无重复
- 执行顺序完全由代码书写顺序决定
- 是分支、循环结构的基础（分支/循环内部的代码依然遵循顺序执行）

## 二、分支结构（根据条件“选路走”）
分支结构用于**根据不同条件执行不同代码**，核心是“判断条件→选择执行路径”，分为 `if` 分支和 `switch` 分支两类。

### 1. if 分支（灵活的条件判断）
#### 核心概念
通过判断“条件表达式”的真假（`true`/`false`），决定执行哪一段代码，支持“单分支、双分支、多分支”三种形式。

#### （1）单分支 if（满足条件才执行）
- 格式：
  ```java
  if (条件表达式) {
      // 条件为true时执行的代码
  }
  ```
- 示例（判断是否成年）：
  ```java
  public class IfSingleBranch {
      public static void main(String[] args) {
          int age = 18;
          
          // 条件：年龄>=18
          if (age >= 18) {
              System.out.println("你已成年，可以独立开户");
          }
          
          System.out.println("程序结束");
      }
  }
  ```
- 执行结果：
  ```
  你已成年，可以独立开户
  程序结束
  ```
  ✨ 如果把 `age` 改成17，只会输出“程序结束”（条件不满足，跳过if内的代码）。

#### （2）双分支 if-else（二选一执行）
- 格式：
  ```java
  if (条件表达式) {
      // 条件为true时执行
  } else {
      // 条件为false时执行
  }
  ```
- 示例（判断奇偶性）：
  ```java
  public class IfElseBranch {
      public static void main(String[] args) {
          int num = 7;
          
          if (num % 2 == 0) { // 取余等于0是偶数
              System.out.println(num + " 是偶数");
          } else {
              System.out.println(num + " 是奇数");
          }
      }
  }
  ```
- 执行结果：
  ```
  7 是奇数
  ```

#### （3）多分支 if-else if-else（多选一执行）
- 格式：
  ```java
  if (条件1) {
      // 条件1为true时执行
  } else if (条件2) {
      // 条件1为false、条件2为true时执行
  } 
  // 可以加多个else if
  else {
      // 所有条件都为false时执行
  }
  ```
- 示例（成绩等级判断）：
  ```java
  public class IfElseIfBranch {
      public static void main(String[] args) {
          int score = 85;
          
          if (score >= 90) {
              System.out.println("优秀");
          } else if (score >= 80) {
              System.out.println("良好");
          } else if (score >= 60) {
              System.out.println("及格");
          } else {
              System.out.println("不及格");
          }
      }
  }
  ```
- 执行结果：
  ```
  良好
  ```
  ✨ 注意：条件判断是“从上到下”的，一旦某个条件满足，后面的条件不会再判断（比如85满足>=80，就不会判断>=60了）。

### 2. switch 分支（固定值的等值判断）
#### 核心概念
专门用于**“表达式值 == 固定值”** 的等值判断，比多分支if更简洁，适合“枚举类”场景（比如星期、月份、成绩等级固定值）。

#### 格式&核心规则
```java
switch (表达式) { // 表达式只能是：byte/short/int/char/String/枚举
    case 值1:
        // 表达式等于值1时执行的代码
        break; // 必须加！退出switch，避免“穿透”
    case 值2:
        // 表达式等于值2时执行的代码
        break;
    // 可以加多个case
    default:
        // 表达式不等于任何case值时执行的代码（可选）
        break;
}
```

#### 示例（根据星期输出提示）：
```java
public class SwitchBranch {
    public static void main(String[] args) {
        String week = "周二";
        
        switch (week) {
            case "周一":
                System.out.println("开始一周的工作，加油！");
                break;
            case "周二":
                System.out.println("进入工作状态，继续努力");
                break;
            case "周五":
                System.out.println("快周末了，坚持！");
                break;
            default:
                System.out.println("正常上班/休息");
                break;
        }
    }
}
```
- 执行结果：
  ```
  进入工作状态，继续努力
  ```

#### 关键注意点
- ❌ 不能用 `double`/`float`/`long` 作为switch表达式（因为浮点数有精度问题）
- ⚠️ 忘记写 `break` 会导致“case穿透”：比如去掉上面示例中“周二”的break，会同时输出“进入工作状态，继续努力”和“正常上班/休息”
- ✅ `default` 可选，位置也可以不放在最后（但建议放最后，可读性更高）

#### if vs switch 怎么选？
| 场景                | 选 if                | 选 switch            |
|---------------------|----------------------|----------------------|
| 条件是“区间”（如>=80） | ✅ 必须用if           | ❌ 不支持            |
| 条件是“固定值”（如星期） | ✅ 可以用，但代码繁琐 | ✅ 更简洁、可读性高  |
| 条件类型是浮点数     | ✅ 可以用if           | ❌ 不支持            |

## 三、循环结构（重复做同一件事）
### 核心说明
循环结构用于**重复执行一段代码**，直到满足“终止条件”，核心是“循环体+终止条件”，分为 `for`、`while`、`do-while` 三种，同时包含死循环、循环嵌套、循环控制语句等扩展知识点。

### 核心术语
- 循环体：需要重复执行的代码
- 初始化表达式：循环开始前的准备工作（比如定义循环变量）
- 条件表达式：判断是否继续循环（true继续，false退出）
- 更新表达式：每次循环后更新循环变量（避免死循环）

### 1. for 循环（已知循环次数）
#### 核心概念
专为“知道循环次数”的场景设计，把“初始化、条件判断、更新”集中写在一行，结构清晰。

#### 格式
```java
for (初始化表达式; 条件表达式; 更新表达式) {
    循环体; // 条件为true时执行
}
```

#### 执行流程（三步走）
1. 执行**初始化表达式**（仅第一次循环执行）
2. 判断**条件表达式**：
    - true → 执行循环体 → 执行更新表达式 → 回到步骤2
    - false → 退出循环
3. 循环结束，执行后续代码

#### 示例（输出1-5的数字）：
```java
public class ForLoop {
    public static void main(String[] args) {
        // 初始化：i=1；条件：i<=5；更新：i++
        for (int i = 1; i <= 5; i++) {
            System.out.println("当前数字：" + i);
        }
        System.out.println("循环结束");
    }
}
```

#### 执行拆解
| 循环次数 | 初始化(i=1) | 条件(i<=5) | 循环体输出 | 更新(i++) | 新i值 |
|----------|-------------|------------|------------|-----------|-------|
| 1        | 执行        | true       | 当前数字：1 | 执行      | 2     |
| 2        | -           | true       | 当前数字：2 | 执行      | 3     |
| 3        | -           | true       | 当前数字：3 | 执行      | 4     |
| 4        | -           | true       | 当前数字：4 | 执行      | 5     |
| 5        | -           | true       | 当前数字：5 | 执行      | 6     |
| 6        | -           | false      | -          | -         | -     |

**输出结果**：
```
当前数字：1
当前数字：2
当前数字：3
当前数字：4
当前数字：5
循环结束
```

### 2. while 循环（未知循环次数，先判断后执行）
#### 核心概念
适合“不知道循环次数，但知道终止条件”的场景，先判断条件，再执行循环体（可能一次都不执行）。

#### 格式
```java
// 初始化表达式（单独写）
while (条件表达式) {
    循环体;
    更新表达式; // 必须写，否则死循环
}
```

#### 示例（计算1-100的和）：
```java
public class WhileLoop {
    public static void main(String[] args) {
        int i = 1; // 初始化
        int sum = 0; // 存储求和结果
        
        while (i <= 100) { // 条件：i<=100
            sum += i; // 循环体：累加
            i++; // 更新：i自增
        }
        
        System.out.println("1-100的和：" + sum);
    }
}
```
**输出结果**：
```
1-100的和：5050
```

### 3. do-while 循环（未知循环次数，先执行后判断）
#### 核心概念
和while的唯一区别：**先执行一次循环体，再判断条件**（循环体至少执行一次）。

#### 格式
```java
// 初始化表达式
do {
    循环体;
    更新表达式;
} while (条件表达式); // 注意末尾有分号
```

#### 示例（强制输入正确密码）：
```java
import java.util.Scanner;

public class DoWhileLoop {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String password;
        
        do {
            System.out.print("请输入密码（123456）：");
            password = sc.next();
        } while (!password.equals("123456")); // 密码不对就重复输入
        
        System.out.println("密码正确，登录成功！");
    }
}
```

#### 执行结果（输入错误2次，正确1次）：
```
请输入密码（123456）：111
请输入密码（123456）：222
请输入密码（123456）：123456
密码正确，登录成功！
```

### 4. 三种循环对比与选型
| 循环类型 | 执行顺序 | 循环体执行次数 | 语法特点 | 适用场景 |
|----------|----------|----------------|----------|----------|
| for      | 先判断后执行 | 0次或多次（条件不满足时0次） | 初始化、条件、更新集中，控制变量作用域仅限循环内 | 已知循环次数（如遍历数组、固定次数打印） |
| while    | 先判断后执行 | 0次或多次（条件不满足时0次） | 初始化单独书写，控制变量作用域不限，语法灵活 | 未知循环次数，有明确终止条件（可能不执行） |
| do-while | 先执行后判断 | 1次或多次（至少执行1次） | 末尾需加半分号，初始化单独书写 | 未知循环次数，循环体必须执行一次 |

| 场景                | 选 for       | 选 while     | 选 do-while  |
|---------------------|--------------|--------------|--------------|
| 已知循环次数（如遍历10次） | ✅ 首选       | ❌ 代码繁琐   | ❌ 没必要     |
| 未知循环次数，可能不执行 | ❌ 不适合     | ✅ 首选       | ❌ 会多执行一次 |
| 未知循环次数，必须执行一次 | ❌ 不适合     | ❌ 代码繁琐   | ✅ 首选       |

### 5. 死循环
#### 定义
死循环是指循环条件始终为true，没有有效的更新表达式，导致循环无法终止，会一直执行循环体，直至程序强制终止。
#### 常见写法
```java
// 1. for循环死循环（三个表达式均省略，条件默认为true）
for (;;) {
    System.out.println("死循环，持续执行");
}

// 2. while循环死循环（条件直接写true）
while (true) {
    System.out.println("死循环，持续执行");
}

// 3. do-while循环死循环（条件写true）
do {
    System.out.println("死循环，持续执行");
} while (true);
```
#### 注意事项
- ⚠️ 避免无意的死循环（如忘记写更新表达式），会导致程序卡顿、占用过多资源；
- ✅ 合理使用：配合break语句实现“无限循环直到满足某个条件后退出”（如服务器监听请求）。

### 6. 循环嵌套
#### 定义
循环中包含另一个循环，执行时外层循环执行一次，内层循环会完整执行所有次数，直到内层循环终止后，外层循环才会进入下一次执行。
#### 示例（打印3行5列的星号）：
```java
// 外层循环：控制行数（3行）
for (int i = 0; i < 3; i++) {
    // 内层循环：控制每行的列数（5列）
    for (int j = 0; j < 5; j++) {
        System.out.print("* "); // 内层循环执行一次，打印一个星号
    }
    System.out.println(); // 外层循环每执行一次，换行
}
// 输出结果：
// * * * * * 
// * * * * * 
// * * * * * 
```
#### 注意事项
- 嵌套层数不宜过多（通常不超过3层），否则降低代码可读性和执行效率；
- 内层和外层循环的控制变量不能重名，避免变量冲突。

### 7. 循环控制语句（break 与 continue）
#### （1）break：立即退出整个循环
- 作用：立即终止当前所在的整个循环（无论循环条件是否满足），跳出循环体，执行循环后续的代码；也可用于switch语句终止执行。
- 示例（找到第一个能被7整除的数就退出）：
  ```java
  // 遍历1-100，找到第一个能被7整除的数，退出循环
  for (int i = 1; i <= 100; i++) {
      if (i % 7 == 0) {
          System.out.println("找到的第一个能被7整除的数：" + i);
          break; // 立即终止当前for循环，不再继续遍历
      }
  }
  // 输出结果：找到的第一个能被7整除的数：7
  ```
- 注意：循环嵌套中，break仅终止内层循环，外层循环继续执行。

#### （2）continue：跳过当前循环，进入下一次循环
- 作用：跳过当前循环的剩余语句，不终止整个循环，直接进入下一次循环的条件判断。
- 示例（输出1-10的奇数，跳过偶数）：
  ```java
  for (int i = 1; i <= 10; i++) {
      if (i % 2 == 0) {
          continue; // 跳过当前循环的剩余语句，进入下一次循环
      }
      System.out.println(i); // 仅当i为奇数时执行
  }
  // 输出结果：1 3 5 7 9
  ```
- 注意：continue仅跳过本次循环剩余部分，不会终止整个循环；若放在循环体最后一行，无实际作用。

#### break 与 continue 对比
| 语句     | 核心作用                 | 对循环的影响                     | 适用场景                                   |
|----------|--------------------------|----------------------------------|--------------------------------------------|
| break    | 终止当前所在的整个循环   | 直接退出循环，不再执行后续循环   | 找到目标值、满足退出条件时，立即终止循环   |
| continue | 跳过当前循环的剩余语句   | 不终止循环，进入下一次循环判断   | 跳过某些特定条件的循环，继续执行后续循环   |

---

### 总结
1. **顺序结构**：程序最基础的执行方式，代码按书写顺序依次执行，无判断、无重复，是分支和循环结构的基础；
2. **分支结构**：按条件选择执行路径，`if` 适配区间/灵活条件判断，`switch` 适配固定值等值判断，需根据条件类型选型；
3. **循环结构**：实现代码重复执行，`for` 适配已知循环次数，`while` 适配未知次数且可能不执行的场景，`do-while` 适配未知次数且必须执行一次的场景；死循环需配合break使用，循环嵌套控制层数，break/continue分别用于终止循环和跳过本次循环。
