# Java 基础核心知识点详细总结。

## 一、方法（Method）
### 1. 核心概念
方法是封装特定功能的代码块，目的是**代码复用、逻辑解耦**，需通过“定义+调用”才能执行。

### 2. 完整语法与各部分说明
```java
public static int add(int a, int b) { // 修饰符 返回值类型 方法名(形参列表)
    int sum = a + b; // 方法体：实现功能的核心代码
    return sum; // 返回值：与返回值类型一致，结束方法并返回结果
}
```
| 组成部分       | 说明                                                                 |
|----------------|----------------------------------------------------------------------|
| 修饰符         | 入门阶段常用`public static`（公共静态），后续会学习更多访问修饰符     |
| 返回值类型     | 方法执行后返回的数据类型，无返回值时必须写`void`                     |
| 方法名         | 遵循小驼峰命名（如`getScore`），见名知意                             |
| 形参列表       | 接收外部传入的数据，格式`数据类型 参数名`，多个参数用逗号分隔         |
| 方法体         | 实现功能的代码逻辑                                                   |
| return         | ① 有返回值：`return 结果;`（结果类型与返回值类型一致）；② 无返回值：`return;`（可省略，用于提前结束方法） |

### 3. 方法调用
- 静态方法（带`static`）：直接通过`方法名(实参)`调用，实参个数/类型/顺序需与形参匹配；
- 示例：`int result = add(3, 5);`（调用上述`add`方法，结果为8）。

### 4. 关键特性与避坑
- **方法重载**：同一类中，方法名相同 + 形参列表不同（个数/类型/顺序），与返回值类型无关；
  ✅ 合法重载：`add(int a, int b)` 和 `add(double a, double b)`；
  ❌ 非法重载：`int add(int a)` 和 `double add(int a)`（仅返回值不同）。
- **常见错误**：方法嵌套定义（不能在方法内部定义另一个方法）、返回值类型与`return`结果不匹配。

## 二、类型转换
### 1. 自动类型转换（隐式转换）
- **规则**：小范围数据类型 → 大范围数据类型，JVM自动完成，无数据丢失；
- **类型范围（从小到大）**：`byte(1字节) < short(2) < int(4) < long(8) < float(4) < double(8)`，`char(2字节)`参与运算时自动转为`int`；
- 示例：`byte b = 10; int i = b;`（合法，byte自动转int）。

### 2. 强制类型转换（显式转换）
- **规则**：大范围数据类型 → 小范围数据类型，需手动指定目标类型，可能丢失精度/溢出；
- **格式**：`目标类型 变量名 = (目标类型) 待转换值;`；
- 示例与避坑：
  ```java
  double num = 3.14;
  int n1 = (int) num; // 结果为3（截断小数，非四舍五入）
  int n2 = 128;
  byte b2 = (byte) n2; // 结果为-128（byte范围-128~127，溢出后按补码计算）
  ```

### 3. 表达式的自动类型提升
- **规则**：表达式中，所有小范围类型会自动提升为表达式的“最高类型”，再参与运算；
- 核心示例：
  ```java
  byte a = 10;
  byte b = 20;
  // int c = a + b; // 必须用int接收，因为byte运算时自动提升为int
  byte c = (byte) (a + b); // 如需byte接收，需强制转换
  ```

## 三、输入输出（I/O）
### 1. 输出（控制台打印）
| 语句                | 说明                     | 示例                  | 输出结果       |
|---------------------|--------------------------|-----------------------|----------------|
| `System.out.println()` | 打印内容后换行           | `System.out.println("Hello");` | Hello（换行）  |
| `System.out.print()`   | 打印内容后不换行         | `System.out.print("Java");`    | Java（不换行） |

### 2. 输入（Scanner工具）
#### 步骤与完整示例
```java
// 1. 导包：必须写在类定义之前
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        // 2. 创建Scanner对象，关联键盘输入
        Scanner sc = new Scanner(System.in);
        
        // 3. 接收数据：提示用户输入，再读取
        System.out.print("请输入年龄：");
        int age = sc.nextInt(); // 读取整数
        System.out.print("请输入姓名：");
        String name = sc.next(); // 读取字符串（以空格/回车为分隔）
        
        // 4. 输出验证
        System.out.println("姓名：" + name + "，年龄：" + age);
        
        // 可选：关闭Scanner（避免资源占用）
        sc.close();
    }
}
```
#### 常用读取方法
- `sc.nextInt()`：读取整数（int）；
- `sc.nextDouble()`：读取小数（double）；
- `sc.next()`：读取字符串（不包含空格）；
- `sc.nextLine()`：读取整行字符串（包含空格）。

## 四、运算符体系
### 1. 算术运算符
| 符号 | 作用       | 关键说明                                                                 | 示例                | 结果  |
|------|------------|--------------------------------------------------------------------------|---------------------|-------|
| `+`  | 加法/拼接  | 数值间为加法；含字符串时为拼接，遵循“从左到右执行”                       | `1 + 2 + "a"`       | `"3a"`|
| `-`  | 减法       | 普通数值运算                                                             | `5 - 2`             | 3     |
| `*`  | 乘法       | 普通数值运算                                                             | `3 * 4`             | 12    |
| `/`  | 除法       | 整数相除截断小数；除数不能为0（否则报错）                                | `10 / 3`            | 3     |
| `%`  | 取余       | 结果符号与被除数一致；常用于判断奇偶、周期问题                           | `10 % 3`、`-10 % 3` | 1、-1 |
| `++` | 自增       | 仅操作变量；前置（`++a`）先加1后运算，后置（`a++`）先运算后加1           | `int a=10; a++`     | a=11  |
| `--` | 自减       | 规则同自增，仅为减1                                                     | `int a=10; --a`     | a=9   |

### 2. 赋值运算符
| 符号 | 名称       | 格式       | 等价形式                  | 核心特性                     |
|------|------------|------------|---------------------------|------------------------------|
| `=`  | 基本赋值   | `a = 10`   | -                         | 从右向左赋值                 |
| `+=` | 加后赋值   | `a += 5`   | `a = (a的类型)(a + 5)`    | 隐含强制类型转换，避免报错   |
| `-=` | 减后赋值   | `a -= 5`   | `a = (a的类型)(a - 5)`    | 同上                         |
| `*=` | 乘后赋值   | `a *= 5`   | `a = (a的类型)(a * 5)`    | 同上                         |
| `/=` | 除后赋值   | `a /= 5`   | `a = (a的类型)(a / 5)`    | 同上                         |
| `%=` | 取余后赋值 | `a %= 5`   | `a = (a的类型)(a % 5)`    | 同上                         |

✅ 实用示例（避免类型报错）：
```java
byte a = 10;
a += 20; // 等价于a = (byte)(a + 20)，结果为30（合法）
// a = a + 20; // 报错：a+20是int类型，不能直接赋值给byte
```

### 3. 关系运算符
- **作用**：判断两个数据的关系，结果永远是`boolean`类型（`true`/`false`）；
- **核心符号**：`>`（大于）、`>=`（大于等于）、`<`（小于）、`<=`（小于等于）、`==`（等于）、`!=`（不等于）；
- **避坑要点**：
  ❌ 错误：`if (score = 60)`（赋值，永远为true）；
  ✅ 正确：`if (score == 60)`（判断相等）。

### 4. 逻辑运算符（组合布尔条件）
| 符号 | 名称     | 运算规则                | 短路特性       | 开发建议               | 示例                  | 结果  |
|------|----------|-------------------------|----------------|------------------------|-----------------------|-------|
| `&`  | 逻辑与   | 全true才true，有false则false | 无（左右都执行） | 极少使用               | `2>1 & 3>2`           | true  |
| `|`  | 逻辑或   | 有true就true，全false才false | 无（左右都执行） | 极少使用               | `2>1 | 3<2`           | true  |
| `!`  | 逻辑非   | 取反（!true=false）     | -              | 常用                   | `!(2>1)`              | false |
| `^`  | 逻辑异或 | 两边不同则true，相同则false | -              | 极少使用               | `2>1 ^ 3<2`           | true  |
| `&&` | 短路与   | 同逻辑与                | 左false则右不执行 | 优先使用（提升效率）| `2<1 && 3>2`          | false |
| `||` | 短路或   | 同逻辑或                | 左true则右不执行 | 优先使用（提升效率）| `2>1 || 3<2`          | true  |

✅ 短路特性实用示例（避免报错）：
```java
int a = 10;
// if (a > 20 && 10 / 0 == 0) { // 左为false，右侧10/0不会执行，无报错
// }
// if (a > 20 & 10 / 0 == 0) { // 左右都执行，10/0报错
// }
```

### 5. 三元运算符（简化if-else）
#### 语法与执行流程
```java
// 格式：条件表达式 ? 值1 : 值2;
int score = 85;
String result = score >= 60 ? "及格" : "不及格"; // 条件为true，返回"及格"
```
#### 执行步骤：
1. 计算“条件表达式”的布尔值；
2. 若为`true`，执行并返回`值1`；
3. 若为`false`，执行并返回`值2`。

#### 避坑要点：
- `值1`和`值2`的类型必须一致（或满足自动转换）；
  ❌ 错误：`score >= 60 ? "及格" : 0`（字符串与int类型不匹配）；
- 结果必须被使用（赋值/传参），不能单独存在；
  ❌ 错误：`score >= 60 ? "及格" : "不及格";`（无使用场景）。

### 总结
1. 方法的核心是“定义规范、调用传参”，重载是提升代码灵活性的关键；
2. 类型转换需关注“范围匹配”，自动转换安全，强制转换需警惕精度/溢出问题；
3. 输入输出是程序与用户交互的基础，Scanner需按步骤使用，注意数据类型匹配；
4. 运算符需区分场景：`+`的双用途、`++`的前后置差异、`&&/||`的短路特性是高频考点，三元运算符是简化条件判断的高效工具。
