## 二、字面量（数据书写格式）
### 1. 核心规则
| 类型     | 写法示例       | 关键要求                  |
| :------- | :------------- | :------------------------ |
| 字符     | `'A'`、`'0'`   | 单引号，且仅包含1个字符   |

## 三、变量
### 1. 核心知识点
- 本质：内存中存储数据的“盒子”，数据可替换
- 定义格式：`数据类型 变量名 = 数据;`（例：`int age = 18;`）
- 用途：存储会变化的数据（如账户余额、游戏分数）

## 四、计算机存储基础
### 1. 核心概念
- 底层存储：所有数据最终以**二进制（0/1）** 存储
- 最小单位：字节（Byte），`1Byte = 8bit`
- 字符存储：通过 ASCII 码表（如 `'A'` 对应数字 65，存65的二进制）
- 进制标识：二进制`0b`开头、八进制`0`开头、十六进制`0x`开头

## 六、进制转换（核心计算规则）
### 1. 二进制 → 十进制（按权展开法）
- **规则**：从右往左，每位数字 × $2$ 的位数次方（从0开始），求和。
- **示例**：二进制 `1101` → 十进制 `13`
  $1×2^3 + 1×2^2 + 0×2^1 + 1×2^0 = 8 + 4 + 0 + 1 = 13$

### 2. 二进制 → 八进制（3位分组法）
- **规则**：从右往左，每**3位**二进制为一组（不足补0），每组转成对应八进制数。
- **示例**：`0110001` → 分组`001 100 001` → 八进制`141`

### 3. 二进制 → 十六进制（4位分组法）
- **规则**：从右往左，每**4位**二进制为一组（不足补0），每组转成对应十六进制数（0-9、A-F）。
- **核心**：0-15 对应 0-9、A(10)、B(11)、C(12)、D(13)、E(14)、F(15)

## 八、关键字与标识符（命名规则核心）
### 1. 关键字
- **定义**：Java 自带的、具有特殊含义的专用词汇。
- **禁忌**：**不能**用作类名、变量名等，否则程序报错。

### 2. 标识符
- **定义**：程序中自定义的名称（如变量名、类名、方法名）。
- **命名规则（必守）**：
    1. 由数字、字母、下划线（_）、美元符（$）组成；
    2. **不能以数字开头**；
    3. **不能使用关键字**；
    4. 不能使用特殊符号（如 &、%、# 等）。
