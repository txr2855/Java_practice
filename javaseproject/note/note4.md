### 一、一维数组（基础核心）
#### 1. 数组的本质与核心特性
数组是 Java 中用于**存储固定长度、同数据类型**元素的容器，核心特性：
- ✅ **长度固定**：一旦创建，长度不可改变（想扩容需手动创建新数组并复制元素）
- ✅ **索引访问**：通过 `数组名[索引]` 操作元素，索引从 `0` 开始，最大值为 `数组长度-1`
- ✅ **内存特性**：数组是引用类型，数组变量存储的是内存地址（堆内存存元素，栈内存存地址）

#### 2. 完整初始化与使用示例（新手友好版）
```java
public class OneDimensionalArray {
    public static void main(String[] args) {
        // ========== 1. 静态初始化（推荐：定义时直接赋值） ==========
        // 方式1：简写形式（最常用）
        int[] scores = {95, 88, 76, 92};
        // 方式2：完整形式（语义更清晰，适合变量先声明后赋值场景）
        int[] ages;
        ages = new int[]{18, 20, 22, 24};

        // ========== 2. 动态初始化（先定长度，后赋值） ==========
        String[] names = new String[3]; // 长度为3，默认值：null
        names[0] = "张三"; // 给第1个元素赋值
        names[1] = "李四"; // 给第2个元素赋值
        names[2] = "王五"; // 给第3个元素赋值

        // ========== 3. 核心操作：访问元素 & 获取长度 ==========
        // 访问元素：索引从0开始
        System.out.println("scores数组第2个元素：" + scores[1]); // 输出88
        // 获取长度：数组名.length（属性，不是方法！）
        System.out.println("names数组长度：" + names.length); // 输出3

        // ========== 4. 遍历数组（两种常用方式） ==========
        // 方式1：普通for循环（可操作索引）
        System.out.println("\n普通for循环遍历scores：");
        for (int i = 0; i < scores.length; i++) {
            System.out.print(scores[i] + " "); // 输出：95 88 76 92
        }

        // 方式2：增强for循环（foreach，仅遍历，无法操作索引）
        System.out.println("\n\n增强for循环遍历names：");
        for (String name : names) {
            System.out.print(name + " "); // 输出：张三 李四 王五
        }

        // ========== 5. 动态初始化的默认值演示 ==========
        double[] prices = new double[2]; // 浮点型默认值：0.0
        boolean[] flags = new boolean[2]; // 布尔型默认值：false
        System.out.println("\n\nprices默认值：" + prices[0]); // 输出0.0
        System.out.println("flags默认值：" + flags[0]); // 输出false
    }
}
```

#### 3. 新手高频错误 & 避坑指南
| 错误类型                | 示例代码                  | 错误原因                          | 解决方案                          |
|-------------------------|---------------------------|-----------------------------------|-----------------------------------|
| 索引越界                | `scores[4]`               | 索引超出 `0 ~ length-1` 范围      | 检查循环条件/索引值，确保不越界   |
| 动态初始化语法错误      | `int[] arr = new int[3]{1,2,3};` | 动态初始化不能同时指定长度和赋值  | 选静态初始化 `int[] arr = {1,2,3};` |
| 空指针异常              | `int[] arr = null; arr[0] = 1;` | 数组变量为null，未指向实际数组    | 先初始化数组 `arr = new int[1];`  |

### 二、二维数组（数组的数组）
#### 1. 本质与结构
二维数组可以理解为**“数组的数组”**：外层数组的每个元素，都是一个一维数组（每行可以是不同长度的一维数组，即“不规则数组”）。

#### 2. 完整使用示例（含遍历+修改）
```java
public class TwoDimensionalArray {
    public static void main(String[] args) {
        // ========== 1. 静态初始化（不规则二维数组） ==========
        int[][] matrix = {
            {12, 24, 36},    // 第0行（3个元素）
            {666, 888},      // 第1行（2个元素）
            {10, 20, 30},    // 第2行（3个元素）
            {999}            // 第3行（1个元素）
        };

        // ========== 2. 核心操作：访问元素 ==========
        // 访问第2行（索引2）的第1个元素（索引1）：20
        System.out.println("matrix[2][1] = " + matrix[2][1]); 
        // 修改第3行（索引3）的第0个元素为111
        matrix[3][0] = 111;
        System.out.println("修改后matrix[3][0] = " + matrix[3][0]); // 输出111

        // ========== 3. 遍历二维数组（嵌套循环） ==========
        System.out.println("\n遍历整个二维数组：");
        // 外层循环：遍历每一行（一维数组）
        for (int i = 0; i < matrix.length; i++) {
            // 内层循环：遍历当前行的每个元素
            for (int j = 0; j < matrix[i].length; j++) {
                System.out.print(matrix[i][j] + "\t"); // \t：制表符，对齐输出
            }
            System.out.println(); // 每行结束后换行
        }

        // ========== 4. 动态初始化二维数组 ==========
        // 方式1：指定行数和列数（规则数组）
        int[][] arr1 = new int[2][3]; // 2行3列，默认值0
        arr1[0][1] = 5; // 给第0行第1列赋值5
        // 方式2：只指定行数，列数后续定义（不规则数组）
        int[][] arr2 = new int[3][]; // 3行，每行未初始化
        arr2[0] = new int[]{1,2}; // 第0行初始化2个元素
        arr2[1] = new int[4];     // 第1行初始化4个元素（默认0）
    }
}
```

#### 3. 输出结果说明
上述代码运行后，二维数组遍历部分的输出：
```
遍历整个二维数组：
12	24	36	
666	888	
10	20	30	
111	
```

### 三、核心知识点总结
1. **一维数组**：长度固定、索引从0开始，`length`是属性（不是方法），动态初始化有默认值（数值型0/0.0、布尔型false、引用型null）。
2. **二维数组**：本质是“数组的数组”，支持不规则结构，遍历需嵌套循环（外层遍历行，内层遍历列）。
3. **新手避坑**：避免索引越界、动态初始化不同时指定长度和赋值、操作数组前确保数组不为null。
