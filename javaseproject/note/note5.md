# Java 面向对象核心知识点详细总结
## 一、类与对象基础
### 1. 核心概念
- **类**：是描述一类事物的**模板/设计图**，抽取多个对象的共性（属性+行为），定义了对象能拥有的数据和能执行的操作。
- **对象**：是类的**具体实例**，代表现实中一个具体的事物，占用堆内存空间，每个对象有独立的属性值（实例变量）。
- **关系**：类是抽象的，对象是具体的；通过`new 类名()`调用构造器创建对象，一个类可以创建多个不同的对象。

### 2. 内存模型
- **栈内存**：存储对象变量（如`Student s`），仅保存对象在堆内存的地址引用，方法执行完毕后栈帧释放。
- **堆内存**：存储对象的实际数据（属性值），每个`new`操作都会在堆中开辟新空间，对象无引用时由GC（垃圾回收器）回收。
- **方法区**：存储类的元信息（属性定义、方法定义、静态成员），所有对象共享类的方法和静态成员。

## 二、构造器（构造方法）
### 1. 核心作用
用于**创建对象并初始化成员变量**，在`new`对象时自动调用，无返回值类型（连`void`都不能写），方法名必须与类名完全一致。

### 2. 分类与规则
- **无参构造器**：类默认自带，若手动定义了有参构造器，默认无参构造器会被覆盖，需手动补充。
  ```java
  public Student() {} // 无参构造器
  ```
- **有参构造器**：创建对象时直接为成员变量赋值，简化代码。
  ```java
  public Student(String name, int age) {
      this.name = name;
      this.age = age;
  }
  ```

## 三、this关键字
### 1. 本质与作用
- `this`是类内部的**隐含变量**，代表“当前调用方法/构造器的对象”：哪个对象调用方法，`this`就指向哪个对象。
- **核心用途**：解决成员变量与局部变量（方法参数）同名的冲突，通过`this.成员变量`明确指代对象的属性。
- **额外用法**：
    - 构造器中`this()`可调用本类其他构造器（必须写在构造器第一行）；
    - 实例方法中可通过`this`调用本类其他实例方法。

### 2. 使用限制
- 仅能在**实例方法/构造器**中使用，静态方法中无法使用（静态方法归属类，无具体对象）。

## 四、封装（面向对象三大特征之一）
### 1. 核心思想
将对象的**数据（成员变量）和操作数据的行为（方法）** 绑定，对外隐藏内部实现细节，仅暴露安全的访问接口，保证数据安全性和代码可维护性。

### 2. 实现规范
- **隐藏数据**：用`private`修饰成员变量，禁止外部直接访问；
- **暴露接口**：用`public`修饰`getter/setter`方法，外部通过方法读写属性（可在方法中添加数据校验逻辑）；
- **实体类（JavaBean）**：封装的标准化应用，专门用于承载数据，要求：
    1. 所有成员变量私有化；
    2. 提供无参构造器（必须）、有参构造器（可选）；
    3. 为每个成员变量提供`getter/setter`方法。

### 3. 示例
```java
public class Student {
    // 私有成员变量（隐藏）
    private String name;
    private int age;
    
    // 无参构造器
    public Student() {}
    
    // 有参构造器
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // getter/setter（暴露接口）
    public String getName() {
        return name;
    }
    public void setName(String name) {
        this.name = name;
    }
    public int getAge() {
        return age;
    }
    public void setAge(int age) {
        // 数据校验：保证年龄合法
        if (age > 0 && age < 150) {
            this.age = age;
        } else {
            System.out.println("年龄不合法");
        }
    }
}
```

## 五、static关键字（静态）
### 1. 核心特性
`static`修饰的成员（变量/方法）归属于**类**，而非对象：内存中仅存一份，被该类所有对象共享，不依赖对象即可访问。

### 2. 静态变量（类变量）
- **用途**：存储所有对象共享的数据（如计数器、全局配置）；
- **访问方式**：推荐`类名.静态变量名`，不推荐`对象名.静态变量名`（易混淆归属）；
- **示例**：
  ```java
  public class User {
      // 静态变量：统计创建的User对象数量
      public static int count = 0;
      
      public User() {
          count++; // 每创建一个对象，计数器+1
      }
  }
  // 访问
  System.out.println(User.count); // 直接通过类名访问
  ```

### 3. 静态方法（类方法）
- **用途**：实现通用工具功能（不依赖对象数据），如工具类中的方法；
- **访问方式**：推荐`类名.静态方法名()`；
- **核心限制**：
    1. 不能直接访问实例变量/实例方法（无具体对象）；
    2. 不能使用`this`关键字；
    3. 可直接访问静态变量/静态方法。

### 4. 工具类最佳实践
工具类专门封装通用功能，内部方法均为静态方法，且私有化构造器防止外部实例化：
```java
public class StringUtil {
    // 私有构造器：禁止创建对象
    private StringUtil() {}
    
    // 静态工具方法：判断字符串是否为空
    public static boolean isEmpty(String str) {
        return str == null || str.trim().length() == 0;
    }
}
// 调用
boolean flag = StringUtil.isEmpty(""); // 直接通过类名调用
```

## 六、方法分类与访问规则
### 1. 方法分类
| 类型       | 修饰符 | 归属   | 调用方式               | 核心场景                     |
|------------|--------|--------|------------------------|------------------------------|
| 静态方法   | static | 类     | 类名.方法名()          | 通用工具功能（无对象依赖）   |
| 实例方法   | 无     | 对象   | 对象名.方法名()        | 描述对象行为（依赖对象数据） |

### 2. 访问规则
| 方法类型   | 可直接访问       | 不可直接访问   | 是否可用this |
|------------|------------------|----------------|--------------|
| 静态方法   | 静态变量/静态方法 | 实例变量/实例方法 | ❌ 不可用    |
| 实例方法   | 所有成员（静态+实例） | 无             | ✅ 可用      |

### 3. main方法说明
`main`方法是程序入口，固定格式`public static void main(String[] args)`：
- `static`：JVM启动时直接通过类名调用，无需创建对象；
- `String[] args`：接收命令行传入的参数，实现程序外部传参。

## 七、核心工程实践要点
1. **封装优先**：所有实体类的成员变量必须私有化，通过`getter/setter`访问，避免直接暴露数据；
2. **静态复用**：通用工具功能（如数据校验、字符串处理）封装为静态方法，放入工具类，提升复用性；
3. **内存优化**：无需创建对象的场景优先用静态方法，避免不必要的对象创建和内存占用；
4. **命名规范**：
    - 类名：大驼峰（如`StudentUtil`）；
    - 方法名/变量名：小驼峰（如`getAge`、`userName`）；
    - 静态常量：全大写+下划线（如`MAX_AGE`）。

## 八、常见易错点
1. **索引越界**：数组访问时索引超出`0 ~ length-1`范围，需检查循环条件或索引值；
2. **空指针异常**：调用`null`对象的方法/属性，需先判断对象是否为`null`；
3. **静态方法误用this**：静态方法中不能使用`this`，也不能直接访问实例成员；
4. **构造器覆盖**：手动定义有参构造器后，若需无参创建对象，必须手动补充无参构造器；
5. **工具类实例化**：工具类需私有化构造器，防止外部通过`new`创建无意义的对象。
